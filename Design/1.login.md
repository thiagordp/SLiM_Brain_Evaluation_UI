# Login page

### Header

**SLiM Brain — Human Evaluation**

The current title feels slightly internal/technical. “HE” already means human evaluation, so “HE Evaluation” is redundant.

Under it, one short line:

> **Restricted access for evaluators.**

That is enough. I would remove the current “SLiM Brain human evaluation” subtitle because the new title already says this.

---

## Password card

The current card is much too wide for a single password field. It stretches almost across the entire viewport, which makes a very small task look unnecessarily large.

I would use a centered card approximately **480–560 px wide**, positioned around the upper-middle of the page.

Inside:

### Heading

**Enter access password**

Then a short explanation:

> Enter the shared evaluator password to continue.

Then:

**Password**

`[••••••••••••••••     👁]`

And underneath, one primary button:

**Continue**

The button should preferably span the width of the input, or at least be substantially wider than the current small `Enter` button.

I would use **Continue**, not **Enter**. “Continue” describes what happens; “Enter” is somewhat ambiguous.

---

## Complete layout

Something approximately like:

```text
                SLiM Brain — Human Evaluation
                Restricted access for evaluators.


              ┌───────────────────────────────┐
              │ Enter access password         │
              │                               │
              │ Enter the shared evaluator    │
              │ password to continue.         │
              │                               │
              │ Password                      │
              │ [••••••••••••••••       👁]  │
              │                               │
              │ [         Continue          ] │
              └───────────────────────────────┘
```

Not literally centred vertically; I would leave it around **25–30% from the top**, so the page does not feel empty or disconnected.

## Behaviour

I would keep:

* password masked by default;
* eye icon to reveal/hide;
* `Enter` keyboard key submits the form;
* successful password → immediately proceed to **Evaluator name**;
* no navigation/menu visible before authentication.

If incorrect, show a simple inline error below the field:

> **Incorrect password. Please try again.**

No large red alert box unless necessary.

I would not add:

* “Forgot password?”
* account creation;
* usernames;
* explanatory security text;
* training/evaluation mode here;
* study instructions here.


## One visual issue in the current screenshot

The strongest problem is not the styling itself; it is the **scale mismatch**:

* very large heading;
* extremely wide form;
* tiny button;
* huge unused whitespace.

Reducing the content width will make the interface immediately feel more deliberate and professional without adding decoration.

So my recommended final wording is:

**SLiM Brain — Human Evaluation**
*Restricted access for evaluators.*

**Enter access password**
*Enter the shared evaluator password to continue.*

**Password**
`[ password field ]`

**Continue**
