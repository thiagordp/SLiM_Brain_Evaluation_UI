# Record: Synthesis

An answer to a question about the literature, kept so later answers can build on it. One page per synthesis, in `wiki/syntheses/`.

A synthesis answers; a hypothesis asks (`schema/hypothesis.md`). A synthesis is a reading of claims that already exist, so it rests on evidence and needs no test. A hypothesis is a conjecture the corpus cannot settle, so it carries the query that would settle it.

Neither is ever cited as evidence: a later answer cites claims.

## Fields

- **`id`** — prefixed `SYN-`. Example: `SYN-0001`.

- **`question`** — the question the synthesis answers, as it was asked.

- **`date`** — when it was written.

- **`claims`** — every claim id the answer rests on. An answer resting on no claim is not a synthesis.

- **`run_ids`** — `schema/run.md`. The run carries the model and the corpus size, which is what tells a later reader how much the answer was drawn from.
